# Graphormer PCQM4Mv2 focused causal analysis

## Deliverable

The endpoint is
[`experiments/methodology/graphormer_pcqm4mv2_causal_colab.ipynb`](../experiments/methodology/graphormer_pcqm4mv2_causal_colab.ipynb).
It runs or resumes four focused tests from Google Drive and exports four publication figures as
600-DPI PNGs, vector PDFs, and JSON metadata sidecars:

1. the frozen semantic/structural specialist gate;
2. restoration and injection, with gross and direction-aligned effects;
3. donor-wise necessity; and
4. aggregate `J` versus clean single-head ablation.

The normative intervention, output-coordinate, split, and aggregation definitions remain those in
[`src/graph_specialisation_metrics/README.md`](../src/graph_specialisation_metrics/README.md).
This focused workflow adds a stricter score-only head gate and a smaller causal target manifest; it
does not redefine the canonical score.

## Fixed sample design

- 128 discovery molecules select and match heads.
- 128 disjoint causal molecules estimate restoration, injection, and necessity.
- 128 further disjoint clean-ablation molecules estimate every head's clean importance.
- Each selected causal graph uses six sources and eight donor events per source.
- Every interval uses the registered 2,000-draw hierarchical percentile bootstrap.
- Semantic and structural channels keep the same graph draw but resample their source/donor
  hierarchies independently.

The three 128-molecule splits and semantic donor pool are generated by the canonical split
machinery and are fingerprinted in the cache contract.

## Frozen specialist gate

The earlier proposal to require a point threshold on 95% of individual molecules is not used as
the classifier. With 128 molecules it would confound genuine between-molecule heterogeneity with
measurement noise and turn one arbitrary count boundary into the family label.

Instead, the discovery event table is hierarchically bootstrapped. In each draw, aggregate semantic
and structural scores are computed and converted to the usual coordinates:

```text
J     = 0.5 * (S_sem / mean_h(S_sem) + S_str / mean_h(S_str))
D_rel = (S_sem / mean_h(S_sem) - S_str / mean_h(S_str))
        / (S_sem / mean_h(S_sem) + S_str / mean_h(S_str) + eps)
```

A head is frozen as:

```text
semantic specialist   if P_boot(J >= 0.20 and D_rel > +0.10) >= 0.95
structural specialist if P_boot(J >= 0.20 and D_rel < -0.10) >= 0.95
supported generalist  if P_boot(J >= 0.20 and |D_rel| <= 0.10) >= 0.95
unresolved            otherwise, when point-active
inactive              when aggregate J < 0.20
```

Thus a directional label needs both signal and stable direction. A head that changes sign, sits
near the threshold, or is active only inconsistently is not forced into either specialist group.
The exact gate and all matching are frozen before causal outputs are computed.

For transparency only, the cache also reports molecule-level `D_rel` under the single frozen
discovery-wide semantic and structural normalization constants. It never renormalizes the head
scores separately inside each molecule, and this diagnostic does not override the bootstrap gate.

At least three one-to-one semantic/structural specialist pairs are required for the causal group
tests. With fewer pairs, the restoration/injection and necessity panels explicitly report “not
estimable”; thresholds are not relaxed after looking at causal outcomes. The all-head clean
ablation test remains estimable independently.

## `J` matching

Semantic and structural specialists are matched one-to-one without replacement by minimum total
absolute aggregate-`J` difference (Hungarian assignment). Layer gaps are recorded as balance
diagnostics but are not another matching constraint.

The opposite-sign comparison pools are:

```text
semantic-specialist null pool:   point-active heads with aggregate D_rel < 0
structural-specialist null pool: point-active heads with aggregate D_rel > 0
```

Each specialist is matched without replacement to the closest available `J` in the relevant pool.
These controls are not called specialists unless they independently pass the confidence gate. A
specialist and its `J`-matched head control are always evaluated on the same causal donor event.

## Causal endpoints

All patches replace one head's complete routed output immediately before Graphormer's attention
`out_proj`, at the graph token and every molecular-node carrier. Let `z_0` be the clean output,
`z_e` the donor-event output, and `Delta_e = z_0 - z_e`.

### Restoration

Run the intervened graph and insert the head's clean activation:

```text
z_R       = z(event input; head <- clean head output)
R_gross   = ||z_R - z_e||_2
R_aligned = <z_R - z_e, Delta_e> / (||Delta_e||_2 + eps)
```

Positive aligned restoration moves back toward the clean prediction.

### Injection

Run the clean graph and insert the head's activation from the same donor event:

```text
z_I       = z(clean input; head <- event head output)
I_gross   = ||z_I - z_0||_2
I_aligned = <z_I - z_0, -Delta_e> / (||Delta_e||_2 + eps)
```

Positive aligned injection moves toward the intervened prediction. Gross and aligned movement are
reported separately so large orthogonal changes are not mislabelled as mediation.

### Alternative-donor activation control

For each original event, choose another already sampled donor event with:

1. the same graph, channel, source, and degree-matching tier;
2. a distinct donor draw and payload fingerprint; and
3. the nearest input dose, with deterministic tie-breaking.

There is no hard dose-gap caliper. The absolute gap is cached and summarized. Restoration and
injection are recomputed with that alternative head activation, aligned to the original event
direction, and subtracted endpoint by endpoint:

```text
R_gross_adj = R_gross_matched - R_gross_alternative
R_align_adj = R_align_matched - R_align_alternative
I_gross_adj = I_gross_matched - I_gross_alternative
I_align_adj = I_align_matched - I_align_alternative
```

Events without an eligible distinct-payload donor are excluded from adjusted patch estimates and
counted. There is no self-control fallback. Both clean-to-clean and event-to-event identity-patch
errors are retained as numerical audits.

### Necessity

Ablate the head in both clean and event runs:

```text
Delta_e_minus_h = z(clean, -h) - z(event, -h)
removed_h       = Delta_e - Delta_e_minus_h
N_gross         = ||removed_h||_2
N_aligned       = <removed_h, Delta_e> / (||Delta_e||_2 + eps)
N_gross_fraction = N_gross / ||Delta_e||_2
N_fraction       = <removed_h, Delta_e> / ||Delta_e||_2^2
```

`N_fraction` is primary. Values outside `[0, 1]` are retained because reversal and overshoot are
possible. Necessity is a differential ablation and therefore uses the `J`-matched head comparison,
not the alternative-activation subtraction.

### Formal specialisation contrast

For each endpoint `E`, the specialist interaction is:

```text
[E(semantic heads, semantic events) - E(semantic heads, structural events)]
- [E(structural heads, semantic events) - E(structural heads, structural events)]
```

The predicted sign is positive. The cache also reports each specialist minus its opposite-sign,
`J`-matched head on the target-matched event channel.

## Clean ablation

Every attention head is independently zeroed on each clean-ablation molecule:

```text
A_h,g = ||z_clean,g - z_clean,g,-h||_2
A_h   = mean_g A_h,g
```

The result reports the all-head Spearman correlation between discovery `J_h` and `A_h`, its graph
bootstrap interval, and a layer-adjusted standardized coefficient. No `D_rel` gate is used for this
test and no OLS trend line is plotted for the rank correlation.

## Backend, cache, and resume design

`GraphormerBackend` exposes batched `patch_individual_heads` and
`ablate_individual_heads`. Each replica has one `(layer, head)` assignment. The hook changes only
that head but changes it at every carrier token. Execution head/event batch sizes and CUDA OOM
backoff do not alter the scientific fingerprint.

The Drive output root contains focused score shards plus the focused artifacts. Complete
canonical graph shards from an interrupted earlier run are accepted as read-through inputs, but
the focused consolidation deliberately skips distance-profile, attention, family, and canonical
coordinate bootstraps:

```text
<OUTPUT_ROOT>/
  focused_causal_protocol.json
  graphormer_pcqm4mv2/seed_0/
    model.json
    cache/
      focused/
        scores/
          raw_inputs_v1.pt
          {semantic,structural}/graph_*.pt
        gate.pt
        events/{semantic,structural}/graph_*.pt
        clean_ablation/graph_*.pt
        core_tests.pt
    figures/focused_causal/
      01_specialist_gate_map.{png,pdf,metadata.json}
      02_restoration_injection.{png,pdf,metadata.json}
      03_donor_wise_necessity.{png,pdf,metadata.json}
      04_J_vs_clean_ablation.{png,pdf,metadata.json}
    focused_causal_manifest.json
```

Each graph/channel causal shard contains donor identity, payload fingerprints, matched and
alternative doses, all raw and adjusted patch endpoints, necessity endpoints, event effect, and
control availability. Completed shards are loaded before any missing shard is run. Contracts bind
the checkpoint, task, output scale, model geometry, split/event manifests, classifier and matching
manifest, thresholds, control rule, endpoint version, and bootstrap policy. Incompatible artifacts
are archived by the canonical cache layer and recomputed.

`PHASE = "run"` runs/resumes measurements, `"all"` also renders, and `"figures"` reads only the
focused score/gate/core cache and does not load Graphormer or PCQM4Mv2. Because `OUTPUT_ROOT` is under the
mounted Drive, both caches and exported figures survive Colab restarts.

## Figure contract

- Figure 1: layer/head category map plus the `D_rel`/`J` plane, confidence thresholds,
  specialist-specialist matches, and opposite-sign `J` nulls.
- Figure 2: restoration/injection by specialist and event channel; adjusted gross and aligned
  effects are primary, with matched and alternative raw components visible.
- Figure 3: aligned and gross necessity fractions with zero and one retained as references.
- Figure 4: all-head `J` versus clean ablation, layer colour, specialist outlines, Spearman interval,
  and layer-adjusted sensitivity coefficient.

The figure layer consumes `core_tests.pt`; it does not rerun or redefine an estimator.

## Verification

The automated checks cover the exact confidence boundary, sign instability, low-`J` exclusion,
opposite-sign `J` matching, aggregate-normalized molecule diagnostics, figure exports and metadata,
the fixed 128/128/128 production configuration, and equivalence of batched versus sequential
Graphormer head interventions when the optional Graphormer runtime is installed. The repository's
broader canonical methodology tests are also run to catch cache, bootstrap, and causal-contract
regressions.
